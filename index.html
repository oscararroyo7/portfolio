Sobre mí

Full Stack, de punta a punta

Soy desarrollador Full Stack con formación práctica tanto en frontend como en backend. Disfruto tomar una idea y llevarla de punta a punta: diseñar la interfaz, construir la lógica del servidor, modelar la base de datos y conectar todo en un producto que funciona de verdad.

Trabajo principalmente con JavaScript (Node.js, Express), PHP y MySQL, y me enfoco en escribir código claro, organizado y fácil de mantener. Me interesan especialmente los sistemas administrativos, los paneles con roles y permisos, y los flujos de autenticación bien resueltos.

Soy una persona metódica a la hora de resolver problemas: primero entiendo el requerimiento, después diseño la estructura de datos, y recién ahí escribo código. Sigo aprendiendo de forma constante — nuevas herramientas, buenas prácticas y patrones que mejoren la calidad de lo que construyo.

01 / Proyecto institucional — La Rioja

Visor Provincial de Prevención de Incendios Forestales

Herramienta ciudadana desarrollada para la Secretaría de Ambiente de La Rioja: cualquier persona toca un punto del mapa y sabe, en el momento, qué tan riesgosa es esa zona y qué hacer al respecto. No es un panel técnico de monitoreo — es una herramienta de prevención pensada para cualquier vecino.

Problema: la prevención depende de que la gente entienda el riesgo, no solo reciba alertas técnicas → Solución: mapa con datos reales + riesgo calculado al instante + contenido educativo separado del código → Resultado: una sola herramienta para consultar, entender y aprender a prevenir
  • Riesgo de incendio en tiempo real al hacer clic en cualquier punto del mapa (clima vía Open-Meteo + fórmula simplificada tipo Fire Weather Index)
  • Capa de focos activos con datos satelitales reales de NASA FIRMS, servidos desde un backend propio — la clave de API nunca llega al navegador
  • Histórico de incendios 2020–2026 agrupado en el mapa con clustering
  • Manual educativo descargable por nivel y protocolos de emergencia, editables sin tocar el código
Stack: HTML5 · CSS3 · JavaScript · Node.js · Leaflet.js · NASA FIRMS API · Open-Meteo API

02 / Plataforma E-commerce + Panel Admin

Sistema Web para Distribuidora

Plataforma completa para que una distribuidora venda y se gestione sin depender de terceros: catálogo público, panel administrativo con roles y permisos, dashboard con métricas en tiempo real y gestión de contenido del home sin tocar código.

Problema: catálogo, pedidos y contenido del sitio gestionados a mano, sin panel propio → Solución: un solo sistema con roles, dashboard y CMS interno → Resultado: ventas, stock y contenido del sitio administrados desde un solo lugar
  • Catálogo público con carrito de compras, construido como isla React sobre el resto del sitio en EJS
  • Login con email/contraseña o Google OAuth, con roles y permisos por tipo de usuario
  • Dashboard con estadísticas de ventas, pedidos, clientes y stock crítico en tiempo real
  • Gestión de productos, categorías, marcas, clientes y pedidos con operaciones CRUD completas
  • Gestión de contenido del home (banners, destacados, footer) con flujo de borrador/publicado, sin tocar código
  • Facturas generadas en PDF del lado del servidor
Stack: Node.js · Express · MySQL · Sequelize · React · EJS · JWT · Google OAuth · Bootstrap
